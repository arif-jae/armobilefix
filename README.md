# บัญชีร้านซ่อมมือถือ

แอพบันทึกงานซ่อม ลูกค้า สต๊อกอะไหล่ รายรับ-รายจ่าย และกำไร
โค้ดเก็บบน GitHub (โฮสต์ด้วย GitHub Pages) ข้อมูลเก็บบน Supabase

## โครงสร้างไฟล์
- `index.html` : ตัวแอพ (ไฟล์เดียว)
- `supabase-setup.sql` : สคริปต์สร้างตารางและสิทธิ์ใน Supabase

## ตั้งค่า Supabase
1. สร้างโปรเจกต์ที่ https://supabase.com
2. SQL Editor → วางและรัน `supabase-setup.sql`
3. Authentication → Users → Add user (สร้างบัญชีพนักงาน)
4. Project Settings → API → คัดลอก Project URL และ anon public key
5. แก้ 2 บรรทัดบนสุดของสคริปต์ใน `index.html`: `SUPABASE_URL` และ `SUPABASE_KEY`

> ใส่เฉพาะ **anon public key** เท่านั้น ห้ามนำ `service_role` key ขึ้น GitHub เด็ดขาด
> ข้อมูลปลอดภัยด้วย Row Level Security (ต้องล็อกอินจึงอ่าน/เขียนได้)

## เผยแพร่ด้วย GitHub Pages
1. สร้าง repository ใหม่ แล้วอัปโหลด `index.html`, `supabase-setup.sql`, `README.md`
2. Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save
3. รอ 1-2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
4. เปิดลิงก์บนทุกเครื่อง ล็อกอินด้วยบัญชีจากข้อ 3 แล้วใช้งานได้เลย

## อัปเดตแอพ
แก้ไฟล์ `index.html` บน GitHub แล้ว commit เว็บจะอัปเดตเองภายในไม่กี่นาที

## ระบบพนักงานหลายคน (เจ้าของ / พนักงานหน้าร้าน)
1. SQL Editor → รัน `supabase-staff.sql` (บัญชีที่มีอยู่แล้วจะกลายเป็น "เจ้าของ" อัตโนมัติ)
2. Authentication → Sign In / Providers → Email: ปิด **Confirm email** (เพื่อให้พนักงานล็อกอินได้ทันที) และต้องเปิดให้สมัครบัญชีใหม่ได้ (Allow new users to sign up)
3. อัปโหลด `index.html` เวอร์ชันใหม่ขึ้น GitHub ทับของเดิม
4. ล็อกอินด้วยบัญชีเจ้าของ → แท็บ "ทีมงาน" → เพิ่มพนักงาน

สิทธิ์:
- **เจ้าของ**: เห็นทุกหน้า รวมสรุปกำไรและทีมงาน เพิ่ม/ปิดใช้งานพนักงานได้
- **พนักงานหน้าร้าน**: ใช้งานซ่อม ลูกค้า อะไหล่ รายรับ-จ่ายได้ แต่ไม่เห็นหน้าสรุปกำไร ไม่เห็นแท็บทีมงาน และลบรายการไม่ได้
- ทุกคนเปลี่ยนรหัสผ่านตัวเองได้ที่ปุ่ม 🔑 มุมบนขวา
- บัญชีที่ไม่มีสิทธิ์ในตาราง profiles หรือถูกปิดใช้งานจะเข้าข้อมูลไม่ได้ แม้สมัครบัญชีเองได้

## แก้ไขข้อมูลทีมงาน (ชื่อ / บทบาท / รหัสผ่าน)
1. SQL Editor → รัน `supabase-team.sql` (ฟังก์ชันตั้งรหัสผ่านให้พนักงาน และตัวกันไม่ให้ไม่เหลือเจ้าของ)
2. อัปโหลด `index.html` เวอร์ชันใหม่ขึ้น GitHub ทับของเดิม
3. แท็บ "ทีมงาน" → แตะที่ชื่อพนักงานเพื่อแก้ไข
- การเปลี่ยนบทบาทมีผลกับหน้าจอของคนนั้นเมื่อเข้าสู่ระบบใหม่
- ถ้าตั้งรหัสผ่านจากแอพไม่ได้ ให้ตั้งที่ Supabase → Authentication → Users แทน
